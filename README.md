## How to use the library

1. Choose a category that matches your project or the style you want to explore.
2. Select **Watch video** to see the generated result and review its model, aspect ratio, resolution, and duration.
3. Expand **Show full prompt** to inspect the prompt. Select and copy the text in the code block, then adapt it to your subject, setting, action, and visual style.
4. Follow **Original post** to view the creator's source post and context.

Prompts are references, not guaranteed recipes. Results can vary with the model, settings, and input assets.

## Contribute

Suggest a correction or a new case by opening a GitHub issue, or submit a pull request that adds the case to the closest category file. Include:

- A descriptive English title and the complete prompt.
- A working video link and cover image, when available.
- The model, aspect ratio, resolution, duration, publication date, and original post link when known.
- A note confirming that you created the material or have permission to share it.

Please keep attribution and source links intact. For broken links, corrections, or removal requests, open an issue with the case title and category.
